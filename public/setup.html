One-time setup

Connect your private data, Gmail, and daily brief.

The interface works immediately in demo mode. Follow these steps once to turn on cross-device saving and unattended task triage.

Medical-work warning: do not ingest patient names or protected health information until your organization has approved its Google Workspace, GitHub, and OpenAI account configuration and agreements.
1

Create a private data repository

Create a private GitHub repository named something like dayline-data. It can be separate from the public repository that hosts the app.

Create a fine-grained personal access token limited to this repository with Contents: read and write.

2

Connect each device

Return to Dayline → Settings → GitHub data vault. Enter the owner, repository, branch main, path data/workspace.json, and the token.

Leave “Remember token” off on shared devices. Dayline creates the starter file automatically if it is missing.

3

Point automation at the private repository

In the app repository, open Settings → Secrets and variables → Actions.

DAYLINE_DATA_REPORepository variable: your-user/dayline-data
DAYLINE_DATA_TOKENRepository secret: the fine-grained token

If the app and data use one private repository, you can skip both values.

4

Authorize read-only Gmail access

  • Enable the Gmail API in a Google Cloud project.
  • Create an OAuth consent screen and add your Gmail as a test user if needed.
  • Create a Desktop app OAuth client.
  • From the project folder, set GMAIL_CLIENT_ID and GMAIL_CLIENT_SECRET, then run node scripts/google-oauth.mjs.
  • Open the printed link and copy the returned refresh token.

Add these three GitHub Actions secrets:

GMAIL_CLIENT_IDGoogle Desktop OAuth client ID
GMAIL_CLIENT_SECRETGoogle Desktop OAuth client secret
GMAIL_REFRESH_TOKENOne-time helper result; treat as a password
5

Enable OpenAI planning

Add an OpenAI API key as the GitHub Actions secret OPENAI_API_KEY. Dayline uses it for actionable-email classification, business routing, one-paragraph daily briefs, and task tips.

This is optional. Without the key, keyword routing and the built-in brief still work.

6

Test and install

Open the GitHub Actions tab and manually run Dayline automation. Return to Settings and select Sync now. Then enable browser notifications.

On your phone, open the Pages URL and choose Add to Home Screen. The app checks GitHub every minute while it is open.

The scheduled workflow checks Gmail every 15 minutes. GitHub may delay scheduled jobs during busy periods. The app does not send, delete, label, or mark email read.

You’re ready.

Add one real task, open the app on your other device, and press Sync now to verify the shared GitHub workspace.
